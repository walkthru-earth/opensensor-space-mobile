# Peacock expression artwork

Generated with the built-in `image_gen` tool on 2026-10-09, using the bundled website peacock at `ui/designsystem/src/commonMain/composeResources/drawable/peacock.webp` as the identity reference for every variation. The original remains the full-body welcome artwork. Eight compact expression portraits ship locally as 512 × 512 lossless WebP with alpha. Their faces and wing gestures support 48–120 dp rendering on Android and iOS. There is no runtime generation or asset download.

`PeacockExpressions.kt` owns the assets and the visual mapping. Fresh air uses a happy wing wave, fair air uses calm, haze uses a concerned wing near the beak, poor and smoky air use a mask, and thick smoke adds feathers over the mask. Missing readings and empty states use confused, intentional resting states use sleeping, and running work uses working. Keep translated state text, advice and WHO colours beside the character. Character gestures are visual cues, not changes to the scientific scale.

Today gives the current reading one large portrait. `PeacockPortrait` layers the image over a smaller white backplate, clipping only the backplate so the head, crest and raised wing extend beyond its top. Both layers rotate together by -5 degrees, with the visible body aligned to the backplate's bottom edge. The portrait is 176 dp, or 136 dp on narrow screens. The daily-average and Smart Sync cards add their own information without repeating the bird.

Selected PNGs were exported without repainting or altering the character. Each was proportionally downscaled to fit a 480 × 480 box and centered on a transparent 512 × 512 canvas, then encoded as lossless WebP. This retains alpha, gives a common margin and stays within the repository's asset-size gate. Generation masters remain outside the checkout. [The review sheet](expressions-review.png) compares every expression at 48, 64 and 96 pixels on light and dark surfaces.

See [supporting prompts](supporting-prompts.md) for confused, sleeping and working. Final prompts for the air expressions follow.
